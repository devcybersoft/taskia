Actúa como desarrollador frontend especializado en HTML5 semántico.

Estoy desarrollando una aplicación web llamada TaskIA para administrar tareas.

Por ahora necesito únicamente construir la estructura HTML de la aplicación.

REQUISITOS:

La página debe incluir:

- encabezado con el nombre TaskIA;
- un texto breve que explique que es un administrador de tareas;
- un formulario para registrar una nueva tarea;
- un campo de texto para escribir la tarea;
- un botón con el texto "Agregar tarea";

taskia/
├── index.html
├── css/

- Utiliza HTML5 semántico.
