# TaskIA

TaskIA es una aplicación web sencilla para administrar tareas. Permite organizar tareas pendientes, marcar tareas completadas y conservar la información en el navegador.

## Funcionalidades

- Agregar tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Mostrar el contador de tareas pendientes.
- Conservar la información mediante `localStorage`.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- `localStorage`
- Git
- GitHub
- GitHub Pages

## Ejecución local

1. Clonar o descargar el repositorio.
2. Abrir el archivo `index.html` en un navegador web.

## Publicación

La aplicación se publica mediante GitHub Pages. Para habilitarla, se debe seleccionar la rama del proyecto como fuente de publicación en la configuración de Pages del repositorio de GitHub.
